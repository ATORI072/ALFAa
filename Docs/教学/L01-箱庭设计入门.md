# L01 箱庭：小空间里的大密度

> 20 分钟读完。读完你会知道：为什么你的第一个项目应该做一个「盒子」，以及怎么判断这个盒子好不好。

---

## 1. 箱庭不是「小地图」

很多人以为箱庭 = 把大地图缩小。不对。

- **小地图**：地方小，内容也少，走两步就逛完；
- **箱庭**：地方小，但**每一平米都有用**——可打的东西、能走的路、能解的锁、能回的旧路。

判断标准只有一句：

> **玩家在 30 秒内做了几个有意义的决定？**

《超级马力欧 奥德赛》的瀑布国不大，但你每走几步就要决定：爬哪面墙、打哪个敌人、走哪条路、要不要回头拿月亮。《杀手》的一张地图也就一个街区，但同一栋楼有 5 种进法、3 种杀法。

**小不是目的，密度才是。**

---

## 2. 常见误区

| 误区 | 表现 | 正解 |
|---|---|---|
| 把地图做大 | 「再加一条街吧」 | 加密度：多一条垂直路线、多一个可射击机关 |
| 一条路走到底 | 走廊 → 房间 → 走廊 | 做环：让玩家能绕回来，从另一侧看同一空间 |
| 平铺 | 所有内容都在地面 | 加垂直：屋顶、地下室、二层看台 |
| 机关是孤立的 | 打一个开关，开一扇门 | 机关互相影响：打灭总闸 → 全楼变黑 → 敌人视野变小 → 但你也看不清 |
| 没有回访 | 打完就走 | 拿到新钥匙/新弹种后，旧区域有新入口 |

## 3. 箱庭四问

每次改关卡，按顺序问：

### Q1 第一眼看到什么？

玩家出生/进房间的 3 秒内，视线应该被一个**地标**抓住：钟塔、破洞的天花板、巨大的异界结晶。

- 地标要「可望不可即」：看得见，但现在去不了；
- 它同时是**方向锚点**：玩家迷路时抬头就能定位。

### Q2 玩家先去哪？

不靠文字，靠**引导**：

- 光：亮的地方更吸引人（但别全亮，要有暗部对比）；
- 动：飘动的窗帘、转动的风扇、闪烁的灯；
- 声：远处的枪声、音乐、水滴；
- 敌人：敌人的朝向会「指路」；
- 构图：门框、走廊尽头的剪影。

**检查方法**：把画面截图给同学看 3 秒，问他「你想往哪走」。答案不一致就改。

### Q3 为什么回来？

好的箱庭会让玩家**走两次同一段路，但感受不同**：

- 第一次：门锁着，只能绕路；
- 第二次：拿到钥匙，直接穿过去，发现「原来这里通向那里」。

回访的燃料：新钥匙、新弹种、新能力、新信息（看到之前看不到的东西）。

### Q4 哪一次交互改变了整个空间？

这是**系统性**：一个动作同时影响多个系统。

例子（本项目）：

> 一枪打爆配电箱 → 整栋楼断电 → 电梯停（路线变化）+ 应急灯亮（光变化）+ 敌人视野缩短（战斗变化）+ 广播响起（叙事）。

一个动作，四个系统。玩家会觉得「这个世界是活的」。

**设计练习**：给你关卡里的每个机关，写下它影响了几件事。只影响 1 件的，考虑合并或删掉。

## 4. 案例速拆

### 《超级马力欧 奥德赛》瀑布国

- 地标：大瀑布 + 恐龙；
- 密度：每 20 米一个月亮/金币/隐藏路；
- 垂直：从瀑布底爬到顶，再滑下来；
- 回访：拿到新帽子能力后，旧地方有新月亮。

### 《杀手》巴黎关卡

- 一个庄园，四条进入路线；
- 每个 NPC 有日程，玩家可以「等」和「利用」；
- 同一个目标，至少 6 种死法。

### 《生化危机 2》警局

- 整个警局是一个大箱庭；
- 钥匙、徽章、阀门构成锁钥网；
- 暴君（追击者）让「熟悉的路线」每次都不一样。

### 《塞尔达》神庙

- 一个房间只教一个机制；
- 教完立刻考；
- 15 分钟内完成「教 → 考 → 合」。

## 5. 练习（30 分钟）

拿一张 A4 纸（或平板），画你的第一个盒子：

1. 画一个 **30×30 m** 的方框，标出三层（1F/2F/3F）；
2. 放 **1 个地标**（画个星星），要求「从出生点能看到，但现在去不了」；
3. 画 **3 条从出生点到地标的路线**（其中一条要绕远）；
4. 放 **2 把锁** 和对应的 **2 把钥匙**，钥匙必须在「看得见但拿不到」的地方；
5. 标 **1 个回访点**：拿到钥匙后，哪条旧路会变成捷径；
6. 用一句话写下：**这个盒子里，玩家做的第一个有意义的决定是什么？**

### 自检表

- [ ] 出生点 3 秒内能看到地标吗？
- [ ] 三条路线是否明显不同（不是三条平行走廊）？
- [ ] 钥匙是否「可见但不可达」？
- [ ] 有没有一条路是「第一次走不通、第二次能走」？
- [ ] 有没有一个机关同时影响 ≥ 2 件事？

## 6. 落到《黄昏校舍》

对照流程规划 §2.3：

- 地标 = 钟塔（从 1F 中庭能看见，但门锁着）；
- 动线 = 中央楼梯（主）/ 消防梯（捷径）/ 电梯（断电，后期恢复）；
- 锁钥 = 保险丝 → 电梯；音乐室钥匙 → 镜面谜题；门禁卡 → 天台；
- 系统性交互 = 打配电箱：断电 + 应急灯 + 敌人视野 + 广播；
- 回访 = 拿到门禁卡后，从 3F 消防梯直接下到 1F，不用再爬楼梯。

**你的第一个决定**：进玄关后，是先去食堂找保险丝（安全但绕），还是先去配电室（近但有敌人）？
