# 策划课 · 课程表

> 目标不是「学会策划」，而是**每节课都能改动当前项目的一处设计**。
> 节奏：20 分钟读 + 30 分钟练 + 1 句「今天可以立刻改的东西」。

## 上课方式

1. 先读本节课文（约 10 分钟）；
2. 做练习（30 分钟），练习必须落在《黄昏校舍》或当前灰盒上；
3. 在日志里写一句：**「今天学到的一个判断标准」**；
4. 下一节课先回顾：上次那条标准，你用上了吗？
