# 零预算资源清单（个人非商用）

> 目标：**不花一分钱**，做出风格统一的 10 分钟箱庭 Demo。
> 原则：优先 CC0；每件资源记录来源与许可证；风格统一 > 单件精度。

---

## 0. 先定美术方向

**低多边形 + 卡通渲染 + 强色彩。** 原因：

- 免费资源绝大多数是 low-poly，硬拼写实只会露馅；
- 卡通描边 + 纯色能把不同来源的模型统一；
- 灯光和雾比贴图更能出效果，成本几乎为零。

**色板**：夕照橙 `#FF9A5A` / 异界青 `#3FD6C8` / 夜紫 `#2B2140` / 高光白 `#FFF4E0`。
**避免**：写实 PBR 材质、4K 贴图、来源不明的「整合包」。

## 2. 角色：VRoid 管线

| 资源 | 用途 | 许可 |
|---|---|---|
| [VRoid Studio](https://vroid.com/en/studio) | 捏人、导出 VRM 1.0 | 免费，导出模型归你 |
| [UniVRM](https://vrm.dev/) | Unity 导入 VRM、Humanoid、SpringBone | MIT |
| [VRoid Hub](https://hub.vroid.com/) | 免费借用的角色模型 | **逐个看作者许可**，多数禁止商用/再配布 |
| [Booth](https://booth.pm/) 免费区 | 服装、发型、小道具 | 逐个看许可，常见「个人使用可」 |

**自制流程**：VRoid 捏脸 → 选校服/发型 → 导出 VRM → UniVRM 导入 → lilToon 材质 → 表情用自带 BlendShape。

**为什么不用 Mixamo 的角色**：写实比例，和动漫场景不搭。Mixamo 只用它的**动画**。

| 来源 | 内容 | 许可 |
|---|---|---|
| [Freesound](https://freesound.org/) | 枪声、脚步、环境音 | 筛 **CC0** |
| [Kenney Audio](https://kenney.nl/assets?q=audio) | UI、impact、界面音 | CC0 |
| [Pixabay Music](https://pixabay.com/music/) | BGM | Pixabay 许可，免费 |
| [OpenGameArt](https://opengameart.org/art-search-advanced?field_art_type_tid%5B%5D=12) | BGM/音效 | 看条目 |
| [VOICEVOX](https://voicevox.hiroshiba.jp/) | 日系动漫语音合成 | 免费，遵守角色使用条款 |

**枪声三层**：近场（干、脆）+ 远场（混响尾）+ 机械声（枪机）。没有素材时，用 Audacity 把一声枪响变调、叠延迟也能糊弄过去。

**配音**：VOICEVOX 生成日语台词 + 中文字幕，成本为零，且「动漫感」比中文 TTS 强。中文可用 Edge-TTS 本地生成。

## 9. 许可与署名

| 许可 | 要做什么 |
|---|---|
| CC0 | 不用署名（仍建议记来源） |
| CC BY | 必须署名（放 `CREDITS.md`） |
| Asset Store EULA | 可商用，但**不能把素材单独转售/再分发** |
| Booth/VRoid Hub | 逐个看，常见「个人使用可、再配布禁止」 |

**建 `CREDITS.md`**，格式：

```
- 角色：自制（VRoid Studio）
- 动画：Mixamo (Adobe) — https://www.mixamo.com/
- 环境：Kenney Furniture Kit (CC0) — https://kenney.nl/assets/furniture-kit
- 音效：Freesound #12345 by user (CC0)
- 字体：Noto Sans SC (OFL)
```

发布 itch.io 时附在页面底部。
