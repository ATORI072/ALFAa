## 1. 一句话基调

**深夜的旧校舍，冷蓝的光，几乎全黑的影，穿水手服的少女背着战术包。**

关键词：夜 / 冷蓝 / 高反差 / 战术少女 / 自拍照片感

反例（明确不要）：黄昏暖橙主调、写实 PBR、高饱和霓虹、明亮卡通、纯赛博。

> 与 v0.1 的冲突：原「黄昏暖橙校舍」降级为**可选变体**，只用于天台/室外段落；主基调改为夜景冷蓝。

## 2. 色板

| 角色 | 名称 | 色值 | 用途 |
|---|---|---|---|
| 主色 | 制服深蓝 | `#1E2440` | 校服、裙、大面积暗部 |
| 环境光 | 冷月蓝 | `#4A6BA8` | 轮廓光、环境反射、阴影里的蓝 |
| 高光 | 冷白 | `#EDEAF2` | 水手领、雪地、灯、文字 |
| 深底 | 近黑 | `#0E1015` | 战术件、暗角、背景深渊 |
| 瞳/强调 | 紫蓝 | `#8A7BC8` | 瞳孔、UI 高亮、交互提示 |
| 暖点 | 肤色暖 | `#F2D5C4` | 皮肤、暖灯、唯一允许的暖色 |
| 点缀 | 臂章黄 | `#E8C15A` | 臂章、警示、Boss 弱点 |

规则：
- **暗部压到近黑**，不是灰、不是紫；只在反射面里留一点冷蓝。
- 暖色只出现在皮肤和灯上，画面暖色面积 ≤ 10%。
- 高对比：亮部敢过曝，暗部敢死黑，中间调少。

## 3. 角色

### 3.1 比例
- 头身比 **6–6.5**（参考图偏矮胖可爱，头偏大）。
- 头大、肩窄、腿短而直，脚小。
- 手可以略大，方便持枪动作被看清。

### 3.2 面部
- 眼睛极大：占脸宽近 1/2，上眼睑厚、下睫毛明显。
- 瞳孔：外圈紫蓝 `#8A7BC8`，内圈亮，**至少一个白色高光点**。
- 必有腮红（粉红斜刷），这是「可爱」的主要来源。
- 嘴极小，几乎一条线；表情靠眉眼。

### 3.3 头发
- 主色深棕黑 `#3A2B2E`，内层/发梢做浅色渐层（粉橙或灰蓝），走路时露出来。
- 发束 10–14 束，块面感强；刘海遮眉。
- 双马尾或低马尾，配白色发饰。

### 3.4 服装（三层）
1. **水手服**：白色大领 + 深蓝裙 `#1E2440` + 蓝领结。
2. **战术层**：黑色背心/背包/弹匣袋 `#0E1015`，肩带交叉。
3. **识别物**：黄色臂章 `#E8C15A`、小手电、绳扣。

### 3.5 道具
- 枪：黑色紧凑型，几何简单，不追求真实枪械细节。
- 背包体积要大，是剪影识别的关键。

## 4. 着色与材质

**lilToon（URP）**，参数按夜景重调：

| 项 | 设定 |
|---|---|
| 着色模型 | Cel 2 阶，阶跃柔和度 0.02（更硬） |
| 阴影色 | 主色 × 冷月蓝 `#4A6BA8`，暗到接近黑 |
| 高光 | 单点硬高光，强度 0.9，范围极窄 |
| 边缘光 | 开启，颜色 `#4A6BA8`，强度 0.5，模拟月光轮廓 |
| 描边 | 世界坐标 0.003–0.005，颜色近黑 `#0E1015` |
| 皮肤 | 单独材质，腮红用贴图，不做 SSS |

环境材质四类：混凝土、金属、白布、雪/湿地面（高反射，用来接月光）。
贴图允许脏、允许划痕——参考图里的箱子、地面都是脏的。

## 5. 光照

- **主光**：冷蓝方向光 `#4A6BA8`，强度 0.8，从侧后方 45° 打，主要出轮廓。
- **补光**：极弱半球光，天空 `#1E2440`，地面 `#0E1015`，强度 0.15。
- **点光**：暖灯 `#F2D5C4`，强度 2–4，衰减快，做画面唯一暖源。
- **反射**：湿地面/雪地必须有反射，这是「冷光感」的来源。
- 阴影：硬阴影，强度 1.0，**允许死黑**。
- 雾：体积雾可选，颜色 `#1E2440`，浓度低；没有体积雾就用线性雾压远景。

原则：**一个画面只有一个暖光点**，其余全靠冷蓝和黑。

## 6. 后期

- Tonemapping：ACES，曝光整体 -0.5。
- Bloom：阈值 0.85，强度 0.6，半径 3——灯、雪、发丝高光都发光。
- 景深：近景人物 f/2.8，背景虚化明显（特写/对话时必开）。
- 暗角：强度 0.35，很重。
- 颗粒：0.08–0.12，模拟手机夜景噪点。
- 色差：极轻 0.03（可选）。
- 色彩分级：暗部推蓝，亮部去黄，饱和 -10。

## 7. 构图语言

- **照片框**：白色四角框 + 轻微畸变，模仿自拍/拍立得；可做成 UI 元素。
- 机位：略低、35mm 广角、人物占画面 60%。
- 允许前景遮挡（门框、箱子、雪花）。
- 参考图那种「并排两个人脸」的构图，可直接用作对话/检查点镜头。

---

## 8. 素材筛选规则

1. 暗部是近黑+冷蓝吗？不是 → 不用。
2. 有没有多余的暖色/高饱和？有 → 降饱和或不用。
3. 剪影清楚吗（背包、裙摆、枪）？不清楚 → 不用。
4. 脏一点没关系，干净发亮反而出戏。
