# Project AB

第三人称 · 动漫美少女 · 射击 × 解谜 · **单箱庭学生版**

> 个人独立项目，非商用。16 周做一个 10–15 分钟的「黄昏校舍」箱庭切片。
> Unity 2022.3 LTS / URP · 全部免费资源。
